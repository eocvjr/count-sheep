# count sheep

A quiet nighttime meadow made as a small bedtime gift. Tap anywhere to send a sleepy sheep hopping across the screen.

**[Open count sheep](https://eocvjr.github.io/count-sheep/)**

## How to use

- Tap the meadow for one sheep. Sheep enter from either side and follow a gentle parabolic arc.
- Open the **options icon** in the bottom-right corner to show or hide the counter. The count appears immediately in the top-right corner.
- Enable **Go dark at a limit**, enter a maximum sheep count, and select **Done**. The limit works with the counter hidden, too.
- When the count reaches the limit, the screen fades completely black. Once the fade finishes, tap to restart from zero with the same options.
- Use the **moon icon** to dim or restore the meadow.

Rapid taps queue sheep at a gentle interval. Leaving the tab clears queued animations. The count and options reset when you reload the page.

## Run locally

Clone the repository or download it as a ZIP, then open `index.html` in your browser.

To make changes, open the folder in VS Code and edit `index.html`. All markup, styles, illustrations, and behavior are in that one file. No installation, dependencies, or build step is needed.

## Deployment

Hosted on **GitHub Pages** from the `main` branch and repository root (`/`). Changes committed to `main` publish automatically, usually within a few minutes.

Watch deployments under [Actions](https://github.com/eocvjr/count-sheep/actions). Pages configuration is under [Settings → Pages](https://github.com/eocvjr/count-sheep/settings/pages).

## Details

- Responsive layout for phones and desktops.
- Silent, with no external assets, cookies, tracking, or sign-in.
- Keyboard-accessible controls with descriptive labels. Focus the meadow button and press Space or Enter to add a sheep; press Escape to close options.
- Reduced-motion preferences use a lower jump arc and remove the blackout fade.

This is a playful wind-down experience, with no sleep tracking or saved progress.
