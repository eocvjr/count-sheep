# count sheep

A quiet nighttime meadow. Tap anywhere for a sheep to hop across the screen.

- Optional counter, hidden by default (tally icon).
- Dimmer (moon icon).
- Mobile-friendly, silent, and dependency-free.
- No cookies, accounts, tracking, or external assets.

## Run and edit

Open `index.html` in a browser. To edit, open this repository folder in VS Code and edit `index.html`. No install or build step is needed.

## Hosting

Current live site: https://little-sheep-night-meadow.adroitlobster.chatgpt.site

The Sites deployment is maintained separately; GitHub commits do not automatically update it.

For GitHub Pages hosting, choose **Settings → Pages → Deploy from a branch → main → / (root)**.

Sheep count resets on reload. Rapid taps queue sheep at a gentle interval. Backgrounding the page clears queued animations. Controls support keyboard navigation and accessible labels.
